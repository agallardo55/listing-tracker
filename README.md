# Casa

A lightweight single-page MVP for tracking listing progress, checklist items, owners, priorities, and notes.

## MVP scope

- Static HTML/CSS/JavaScript app
- No backend required
- Stores data in browser `localStorage`
- Works as a deployable static site

## Local preview

```bash
python3 -m http.server 4173
```

Open:

```text
http://127.0.0.1:4173
```

## Deployment

This MVP is suitable for GitHub Pages, Vercel, or Cloudflare Pages because it is a static single-file app.
